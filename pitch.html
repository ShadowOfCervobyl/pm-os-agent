Agentic Loops for PMs · final project

Cortex: a chief-of-staff agent that drafts and never sends

Weekly status updates and next-sprint stories for a product manager, with a human at every step that matters.

Where it stands: rung 2 of 5, assisted. It has run only on sample data. The gate to the next rung is not met, and this deck shows why.
M1 · The agent line

What Cortex owns, and what stays human

Each action scored on reversibility, blast radius and measurability.

Below the line (Cortex)
  • Pull project state and activity
  • Pick the relevant context
  • Draft the update
  • Propose tone and commitment level
  • Flag risks
  • Propose a capped story batch
Above the line (a person)
  • Choose what to escalate
  • Post an update, or approve a company-wide one
  • Commit a ship date, mark a launch gate
  • Disclose an embargoed project
Hardest call: proposing story and roadmap batches. A cap keeps it below the line. Uncapped, it is not.
M2 · The loop

A request starts a run. Three exits end it.

  • Trigger: a hook. Cron and heartbeat were ruled out because they act without being asked.
  • Done: the draft is saved, stories are queued within the cap, the critic passes, nothing is posted, and every claim cites a source.
  • Success: all of that holds. The run stops at a human checkpoint.
  • Stuck: the same step fails 3 times, the critic rejects 3 revisions, or a bound trips.
  • Escalate: a firm date, a post request, an embargoed project, a batch over the cap, a missing project, or a duplicate request.
M3 · The team

One agent, plus one independent critic

Of four reasons to split, only one held: Cortex cannot grade its own draft.

  • The critic gets a fresh context: the draft and the source log, nothing of Cortex's reasoning.
  • Seven checks: right project, claims traceable to data, within the norms, nothing posted, injections refused, rejections treated as correct escalations, activity data behind every update.
  • The critic also says whether the brief carried an injection. Code then holds any draft after an injection that does not start with ESCALATE. It runs at temperature 0.
  • Code adds three rejections on top: no activity data, an injected brief that does not end in ESCALATE, and a sprint number that is not in the data.
  • On a fail, Cortex revises. After 3 rounds it escalates. A pass goes to the PM, never straight out.
  • Cost: 1 critic call normally, at most 4.

What I learned

The dangerous failure is the quiet one

A missing source does not make the agent fail. It makes the agent fill the gap from the nearest source, in the same confident tone.
  • A bound is a number that code enforces. A line in a prompt is not.
  • A second model is a second opinion. Test it with cases that should fail.
  • What the model can read is a permission decision.
